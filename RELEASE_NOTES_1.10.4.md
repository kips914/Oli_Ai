# OLI 1.10.4 — сервер без «?» и с понятным окном

## Что было

Окно сервера (`OLI.Server.exe` или сервер, запущенный из OLI) вместо русского текста
показывало `??????`: консоль Windows запускалась с OEM-кодировкой (866/437) и растровым
шрифтом без кириллицы, поэтому каждая русская буква выводилась как знак вопроса.

## Что исправлено

### Кириллица в консоли сервера
- Вывод и ввод консоли переводятся в UTF-8, кодовая страница — 65001.
- Windows просит TrueType-шрифт (Consolas) вместо растрового — теперь буквы рисуются.
- Включаются VT-последовательности (цветной вывод работает).
- Всё это в `OLI.Core/ConsoleUi.cs` и применяется на самой первой строке `OLI.Server`
  и в консоли OLI на ПК.

### Понятный стартовый экран сервера
Вместо технической сводки теперь видно то, что нужно для подключения телефона:

```
======================================
 OLI Server  1.10.4
======================================
 Адрес для телефона: http://192.168.1.10:8765
 Все адреса ПК:       192.168.1.10 (Wi-Fi), 10.8.0.2 (WireGuard, виртуальный)
 Данные:              C:\Users\...\AppData\Local\OLI\server
 Модель:              oli @ http://127.0.0.1:8080
 Квота:               1024 МБ на пользователя
 Регистрация:         открыта
 Движок модели:       на связи (http://127.0.0.1:8080)

 В приложении на телефоне: «Свой ПК как сервер» → «Найти мой ПК».
 Ctrl+C — остановить сервер.
```

- Отдельная строка про движок модели: если llama.cpp не запущен, сервер честно пишет
  «НЕ ОТВЕЧАЕТ» вместо того, чтобы молча возвращать ошибку в чат.
- Порт открывается в брандмауэре самим сервером (правило `profile=any`), с понятным
  сообщением, если Windows не дала прав.
- Если сервер не смог запуститься (порт занят и т.п.), окно больше не закрывается
  мгновенно — сообщение об ошибке остаётся на экране до нажатия Enter.
- Ошибки больше не теряются: они пишутся и в консоль, и в `oli.log`.

### Консоль в OLI на ПК
В разделе «Консоль» журналу принудительно задаётся шрифт с кириллицей
(Consolas / Segoe UI), чтобы записи тоже не превращались в вопросы.

## Обновление

- Windows: замените `OLI.exe` (и `OLI.Server.exe`, если запускаете сервер отдельно).
- Android: `OLI-Mobile-1.10.4-release.apk` (версия 1.10.4, code 9).

Сопряжение телефона и ПК из 1.10.3 не изменилось: «Найти мой ПК» по-прежнему находит
сервер сам.
