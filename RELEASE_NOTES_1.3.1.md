# OLI 1.3.1_released.1_released

## Исправления
- Пользовательские данные перенесены из каталога установки в `%LOCALAPPDATA%\\OLI`.
- Настройки, память и профиль сохраняются атомарно.
- Повреждённый settings/profile не ломает запуск: создаётся backup и используются значения по умолчанию.
- Добавлен ограничитель контекста: OLI больше не отправляет бесконечную историю в llama.cpp.
- Настройки контекста теперь реально используются при построении запроса.
- Добавлен единый логгер с уровнями DEBUG/INFO/WARNING/ERROR.
- Добавлена вкладка `🖥 Консоль` с очисткой, копированием и автопрокруткой.
- Поисковая выдача помечается как недоверенный внешний контекст.
- MemoryStore получил структурированные записи, confidence, category, timestamps и дедупликацию.
- Исправлено сохранение пользовательского профиля.
- Mobile Gateway остаётся localhost-only и подготовлен для следующего этапа безопасности.

## Архитектура
- `AppPaths` — пользовательские данные отдельно от установки.
- `ContextBuilder` — ограничение и сборка контекста.
- `OliLog` — единый журнал для консоли и файла.
