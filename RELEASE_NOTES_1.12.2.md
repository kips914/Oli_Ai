# OLI 1.12.2 — телефон реально подключается к ПК

По логу с вашего ПК нашлись три настоящие причины. Все три исправлены.

## 1. Брандмауэр не открывался (главная причина «телефон не подключается»)

В логе: `WARNING SERVER Брандмауэр: правило не добавлено (возможно, отказ в правах администратора)`.

Раньше OLI пытался добавить правило без прав администратора — Windows молча отказывала,
порт оставался закрытым, и телефон не мог достучаться до сервера (при этом сам сервер
работал, и чат с ПК отвечал).

Теперь:
- OLI **запрашивает права администратора (UAC)** и добавляет правило для порта
  **и для самой программы** на всех профилях сети;
- если вы отклонили запрос — в окне показана **готовая команда** для PowerShell:
  `netsh advfirewall firewall add rule name="OLI Server (phone app)" dir=in action=allow protocol=TCP localport=<порт> profile=any`;
- в строке состояния сервера и в пульте администратора теперь **видно**:
  «✔ порт открыт» или «⚠ порт 6767 закрыт брандмауэром»;
- проверяется именно порт правила (а не любое число в его тексте), поэтому старые
  правила для 8765 больше не считаются «открытыми» при вашем порту 6767.

## 2. Ответ был пустым из-за стриминга Ollama

В логе: `Stream finished in 48,61s, chars=0`.

Потоковый ответ разбирался только в формате `data: {...}` (llama.cpp). Теперь
принимается и `data:`-поток, и NDJSON, и варианты с полями `message`/`text` — то, что
присылают разные версии Ollama. Если движок всё же пришлёт поток без текста, OLI
больше не покажет пустой ответ, а честно скажет, сколько строк пришло и что делать.

## 3. Понятные подсказки на телефоне

При «Компьютер не ответил» приложение сразу пишет: **на ПК «Пульт админа» → «🛡 Открыть
порт»**, а если вы не в домашнем Wi-Fi — «🌍 Дам доступ из интернета» и код подключения.

## Что делать после обновления

1. На ПК обновите OLI до 1.12.2, откройте «Пульт админа».
2. Нажмите **«🛡 Открыть порт»** → в запросе Windows **«Да»**.
   В строке сервера должно появиться «порт открыт в брандмауэре».
3. Проверьте, что сервер запущен на вашем порту **6767** (по умолчанию у вас он уже такой).
4. На телефоне (APK 1.12.2): Настройки → «Подключиться по коду» или «Найти мой ПК» →
   «Проверить всё».
5. Дома — адрес `http://<IP ПК>:6767`. Вне дома — «🌍 Дам доступ из интернета» и код.

Если домашний Wi-Fi недоступен совсем (гостевые сети, мобильный интернет) —
интернет-доступ из 1.12 работает и без открытия порта в брандмауэре.
