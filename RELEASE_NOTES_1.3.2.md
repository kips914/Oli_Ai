# OLI 1.3.2 (в разработке)

## Изменения
- `MemoryStore` подключён по-настоящему: раньше `AddAsync` нигде не вызывался, и
  «долгая память» никогда не пополнялась. Теперь модель сама решает, что стоит
  запомнить, и помечает это строкой `OLI_REMEMBER: <факт>` в конце ответа —
  такие строки не показываются пользователю, а сохраняются в
  `data/memory/memory.json` (после миграции — `%LOCALAPPDATA%\OLI\memory\memory.json`).
- Новый протокол `OLI_OPEN: <ссылка>` — если сниппетов из поиска недостаточно,
  модель может запросить полный текст одной или нескольких (до 3) страниц с
  разрешённых сайтов за один раз. Как и поиск, работает только по требованию
  модели, а не на каждое сообщение.
- Цикл поиск → открытие страниц ограничен 3 шагами на одно сообщение
  пользователя, чтобы модель не могла зациклиться.
- Убрана функция сравнения цен по нескольким магазинам (не нужна для текущих
  задач) — поиск и открытие страниц остаются одним общим протоколом для любых
  разрешённых сайтов.
- В `Persona.cs` добавлены конкретные правила для более точного поиска и
  честного использования найденного: как формулировать короткий запрос по
  ключевым словам вместо пересказа вопроса, когда переформулировать запрос
  вместо немедленной сдачи, как проверять релевантность результата, что
  делать при противоречащих источниках и устаревших данных (цены/наличие).
