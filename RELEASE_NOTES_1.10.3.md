# OLI 1.10.3 — телефон находит ПК сам

## Что было не так

Телефон не видел сервер на компьютере, и подключиться можно было только вписав IP
вручную — но его никто не знает, он меняется, а порт 8765 по умолчанию закрыт
брандмауэром Windows. Отсюда «сервер не виден».

## Что исправлено

### Телефон сам находит ваш ПК
- Новый автоматический поиск сервера в локальной сети: приложение проверяет всю свою
  подсеть (`192.168.x.x:8765`) параллельно и подключается к первому ответившему серверу OLI.
- Кнопка **«Найти мой ПК»** на экране входа и в настройках — одно нажатие вместо ввода IP.
- Поиск также запускается сам: при открытии приложения и при повторном входе, если адрес
  ПК изменился (например, роутер выдал новый).
- Сначала проверяется адрес, который работал в прошлый раз, потом — сеть. Виртуальные
  адаптеры (VPN, Hyper-V, Docker) проверяются в последнюю очередь, чтобы не находить
  «сервер», до которого телефон не дотянется.
- Экран входа при недоступном сервере больше не молчит: пишет причину и предлагает поиск.

### Сервер на ПК виден телефону
- Брандмауэр: правило для порта добавляется **для всех профилей сети** (`profile=any`).
  Раньше правило создавалось только для «частной»/«доменной» сети, а Windows очень часто
  помечает домашний Wi-Fi как «общедоступный» — и телефон молча не подключался.
- Порт открывается автоматически при первом запуске сервера. Если приложение запущено
  от администратора, запрос UAC не появляется вообще.
- Сервер поднимается вместе с OLI сразу после установки (раньше нужно было один раз
  запустить его вручную): телефон работает «из коробки».
- Адрес для телефона показывается сразу после запуска сервера, вместе со всеми
  сетевыми адресами этого ПК и пометкой виртуальных адаптеров.
- Адрес выбирается правильнее: настоящий Wi-Fi/Ethernet важнее виртуальных адаптеров,
  APIPA-адреса (169.254.x.x) и loopback больше не предлагаются телефону.

### Попутно
- Исправлены id моделей на сервере: `/api/models` отдавал `k3.pass`/`k3.son`, а сервер и
  приложение ждут `oli-pass`/`oli-son` — из-за этого переключение модели могло не сохраняться.
- Никаких «k3» в API больше нет.

## Что сделать после обновления

1. Установите `OLI.exe` и запустите OLI — сервер стартует сам. Если Windows спросит про
   доступ к сети / права администратора — разрешите (это добавление правила брандмауэра).
2. Установите `OLI-Mobile-1.10.3-release.apk`.
3. В приложении: «Свой ПК как сервер» → **«Найти мой ПК»**. Через 1–3 секунды адрес
   появится сам.
4. Телефон и ПК должны быть в одной Wi-Fi-сети (мобильный интернет не подойдёт).

## Если всё равно не видит

- В OLI на ПК откройте «Пульт админа»: там строка «Адрес для телефона» со всеми адресами.
- Нажмите «🛡 Открыть порт» ещё раз, если правило не добавилось.
- Проверьте, что сеть в Windows не «гостевая» с изоляцией клиентов (в таких сетях
  устройства не видят друг друга) — используйте свой роутер или VPN.
