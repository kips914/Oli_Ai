# OLI 1.9.0 — OLI как сервис: ПК-сервер + Android-приложение

Главное: ваш компьютер теперь **сервер OLI**, а телефон — пульт. Каждый пользователь
регистрируется, входит по логину и паролю и получает **своё личное пространство на 1 ГБ**
для файлов и работы ИИ. Запросы по-прежнему могут приходить и через Telegram-бота на ПК.

## Что нового в ПК-приложении
- **OLI.Server** — новый отдельный сервер (`OLI.Server.exe`) и встроенный сервер в самом OLI:
  аккаунты, сессии, чат, файлы, квоты. Запускается из приложения или отдельным exe.
- **Пульт администратора** (`🛰 Пульт админа`): запуск/остановка сервера, адрес для телефона,
  список пользователей, занятое место, изменение квоты, блокировка, сброс пароля, удаление
  аккаунта вместе с файлами, открытие папки данных в проводнике.
- Настройки сервера прямо в приложении: порт, регистрация (вкл/выкл), код приглашения, квота
  на пользователя (по умолчанию 1 ГБ), токен администратора, доступ модели к файлам.
- `OLI-win-x64.zip` теперь содержит и `OLI.exe`, и `OLI.Server.exe`.

## Android-приложение (APK)
- Вход и **регистрация** с телефона по адресу вашего ПК (например `192.168.1.10:8765`).
- **Чат** с вашей локальной моделью на ПК, история в рамках сессии, новый диалог.
- **Файлы**: просмотр папок, загрузка с телефона, скачивание, удаление, индикатор занятого
  места и полоса квоты (1 ГБ), «скачать всё архивом».
- **Настройки**: адрес сервера, проверка соединения, смена пароля, выход.

## Безопасность паролей
- На сервере хранится только **PBKDF2-HMAC-SHA256** (210 000 итераций) хеш с индивидуальной
  солью — ни администратор, ни тот, кто получит файл `accounts.json`, не узнает пароль.
  Восстановление невозможно, только сброс на новый пароль из пульта.
- Токены сессий хранятся на сервере тоже в виде SHA-256 хеша, живут 30 дней (не более 8 устройств).
- На телефоне логин и пароль лежат в **EncryptedSharedPreferences** (AES-256-GCM, ключ в Android
  Keystore, аппаратная защита при наличии). Из резервных копий хранилище исключено.
- Файлы каждого пользователя изолированы (`users/<id>/`) и не могут выйти за пределы своей папки.
- `run_command` для пользователей сервера выключен: модель не может запускать команды на вашем ПК.

## Обновление
1. Скачайте `OLI.exe` (или `OLI-win-x64.zip`) и `OLI-Mobile-1.9.0-release.apk`.
2. На ПК: «Пульт админа» → «Запустить сервер» → посмотрите адрес для телефона.
3. На телефоне: установите APK, введите адрес, зарегистрируйтесь.
