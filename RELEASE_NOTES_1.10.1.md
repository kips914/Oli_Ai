# OLI 1.10.1 — чище навигация и профиль

## Чаты
* **Убрана нижняя панель** (кнопки «Чат» и «Файлы») — чат занимает весь экран.
* **«Файлы» переехали в настройки** и называются **«Хранилище»**: квота, загрузка,
  скачивание, удаление, архив всего. Открывается из настроек, из профиля и из чата (＋).
* Настройки — по-прежнему шестерёнка в панели чатов (три полоски сверху слева).

## Профиль
* **Кружок справа сверху** в шапке чата — аватар с первой буквой имени.
* Нажатие открывает профиль: **смена имени** (логин не меняется), статистика
  (хранилище, токены за сутки/час, пользователей онлайн), адрес сервера, версия,
  быстрые переходы в настройки и хранилище, выход.

## Модели и текст
* Убраны технические подписи **«k3.pass» / «k3.son»** — остались просто
  **Olim Pass** (флагман) и **Olim Son** (лёгкая).
* Из описаний убраны фразы про «скрываем модель»: в промте осталась только короткая
  строка личности («тебя зовут OLI»), а из экрана «Возможности» — упоминание о скрытии.

## API
`POST /api/profile` — смена отображаемого имени (2–40 символов), остальное без изменений.
