# OLI 1.9.1 — автоподключение и режим просмотра

## Приложение само подключается к серверу
* При запуске APK **сам находит сервер OLI** — адрес вводить не нужно: он зашит в
  приложение (cloud-сервер, который работает на вашем ПК) и показывается строкой
  состояния «Сервер OLI · подключено».
* В настройках и на экране входа есть переключатель **«Свой ПК как сервер»**: включите
  его и вставьте IP компьютера (`192.168.1.10:8765`) — приложение переключится на ваш ПК.
  Выключите — вернётся к серверу OLI.
* Адрес сервера можно менять без переустановки APK: в Cloudflare-воркере появился
  эндпоинт `/api/oli/server`, а в сборке — переменная `OLI_DIRECTORY_URL`
  (`{"server": "https://..."}`).

## Режим просмотра (без регистрации)
* На экране входа — кнопка **«👁 Посмотреть без входа»**: интерфейс открывается целиком
  (чат, файлы, настройки), можно всё нажимать.
* **Запросы не уходят:** сообщение остаётся на экране с пометкой «режим просмотра»,
  файлы — примеры, загрузка/удаление/пароль недоступны.
* В шапке висит баннер «Режим просмотра» с кнопкой «Войти».

## Сервер
* `OLI.Server.exe` умеет **HTTPS напрямую**: `--cert file.pfx --cert-password ***`
  (или обычный HTTP за Cloudflare Tunnel / nginx).
* Учитываются заголовки `X-Forwarded-For/Proto` — за туннелем корректно определяется IP
  (важно для троттлинга входов).
* Без изменений: PBKDF2-хеши паролей, изоляция `users/<id>/`, квота 1 ГБ на пользователя.

## Обновление
1. ПК: новый `OLI.exe` / `OLI.Server.exe` из релиза.
2. Телефон: `OLI-Mobile-1.9.1-release.apk`. Приложение подключится само; если ваш ПК —
   отдельный сервер, включите «Свой ПК как сервер» в настройках.

> Важно про адрес по умолчанию: он задаётся при сборке APK
> (`OLI_DEFAULT_SERVER`), потому что это адрес вашего сервера в интернете. Пока он не
> задан, приложение подключается к `https://oli-cloud.example.com` и предлагает режим
> просмотра либо свой ПК.
